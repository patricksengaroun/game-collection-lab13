# Game Collection

## Week 13: Game of Life II

Menu option 6 becomes a complete simulator: choose a pattern, choose a number of
generations, watch them step by Enter.

Functions to write in `src/game_of_life.rs`: `next_generation`, `load_pattern`,
`population`, and a new `play()`. Your Week 12 functions are the starting point.

Tests: the instructor supplies `block_is_still` and `blinker_returns_after_two`. Write the
glider test and one more of your own.

Run: `cargo run`. Test: `cargo test`.
